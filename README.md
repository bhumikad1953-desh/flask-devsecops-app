# Cloud Native DevSecOps CI/CD Platform

This project demonstrates a Cloud Native DevSecOps CI/CD pipeline using:

- Python Flask
- Git
- GitHub
- Jenkins
- Docker
- SonarQube
- Gitleaks
- Trivy
- Kubernetes
- ArgoCD
- Falco

## Project Description

This project implements a complete Cloud Native DevSecOps CI/CD pipeline. A Flask application is version-controlled using Git and GitHub, automatically built by Jenkins, containerized using Docker, scanned using SonarQube, Gitleaks, and Trivy, deployed to Kubernetes using ArgoCD, and monitored using Falco.
